# 🤖 InterviewPrep AI

## 📝 Chatbot Description

InterviewPrep AI is an intelligent NLP-based chatbot designed to support interview preparation. The chatbot uses Transformer-based sentence embeddings and cosine similarity to understand the semantic meaning of user questions and provide the most relevant answers from a custom question-answer dataset.

Unlike traditional keyword-based chatbots, InterviewPrep AI focuses on sentence meaning rather than exact keyword matching, allowing it to respond more accurately to different forms of similar questions. The chatbot is built with a Streamlit web interface that provides an interactive and user-friendly experience.

This project demonstrates practical applications of Natural Language Processing (NLP), semantic search, and conversational AI while helping users practice interview questions and improve preparation.

---

## 🚀 Features

- Transformer-based sentence embeddings
- Semantic similarity matching using cosine similarity
- Interview question-answer chatbot
- Streamlit web interface
- Chat history support
- Clear chat option
- Dynamic question-answer dataset
- Fast response using saved embeddings (Pickle)
- User-friendly sidebar navigation
